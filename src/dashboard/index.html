Channel performance

Applications use submission attribution. Bookings use the attribution saved with the appointment. Each appointment is counted once on its first verified booking event, including appointments later cancelled. These are period counts, not a conversion cohort.

Campaign performance

Applications are counted by submission date; appointments by their first verified booking date. Both use their saved latest-touch attribution. These period counts are not a conversion cohort. Empty campaign or content values appear as “(not set)”.

SourceMediumCampaignContentApplicationsConfirmed bookings

Booking outcomes

Current status of appointments first booked within the selected window. Each appointment is counted once; rescheduling does not add another booking. Status may change after the reporting window. Active means new or confirmed; other includes invalid or unrecognized statuses.

Pipeline handoff

Only the setter and closer pipelines belong to the new process. Applications remain unbooked until an appointment is verified. These are current totals across all dates.

Data health

Dates use UTC. This dashboard contains aggregate data only. Historical GHL records are not automatically backfilled. Zero means no recorded activity; unavailable data is shown as unavailable.
